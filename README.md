# 💣 Cpp-Minesweeper (控制台扫雷)

一个基于现代 C++ 编写的控制台扫雷游戏。作为大一阶段从“语法练习”迈向“工程开发”的里程碑项目。

## 🎮 核心功能 (Features)

- [x] **随机布雷**：基于 `time()` 种子生成真随机雷区。
- [x] **周围雷数计算**：精准计算任意格子周围 8 个方向的雷数。
- [x] **智能泛洪展开 (Flood Fill)**：点击空白区域（周围无雷）时，自动递归展开连通的空白区域，大幅提升游戏体验。
- [x] **游戏计时**：记录玩家从开局到当前操作的真实耗时。
- [x] **防误触机制**：重复点击已翻开的格子不会触发错误逻辑。
- [x] **状态判定**：完整实现踩雷暴毙 (Game Over) 与清空安全区胜利 (You Win) 的逻辑闭环。

## 🛠️ 技术栈与核心逻辑 (Technical Highlights)

- **数据结构**：使用 `vector<vector<int>>` 构建二维雷区模型与玩家视野视图，分离底层数据与 UI 表现。
- **DFS 深度优先搜索**：在空白区域展开功能中，利用递归实现泛洪算法（Flood Fill），并加入严密的边界检查（防止数组越界与递归死循环）。
- **时间计算**：引入 `<chrono>` 标准库，实现毫秒级精度的游戏计时。
- **状态机思想**：使用 `isPlaying` 布尔变量管理游戏主循环的生命周期，确保状态切换时的逻辑安全。

## 🚀 如何运行 (How to Run)

### 环境要求
- Windows / macOS / Linux
- C++ 编译器 (支持 C++11 及以上，如 GCC/MinGW)

### 编译与运行
在终端中执行以下命令：
```bash
# 编译
g++ main.cpp -o minesweeper -std=c++11

# 运行
./minesweeper
